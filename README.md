# Pharmacy Delivery System

A full-stack pharmacy delivery web application built using ASP.NET Core and SQL Server.  
The system allows users to browse pharmacies, place orders, and manage deliveries efficiently.

## 📌 Overview
This project was developed to simulate a real-world pharmacy delivery platform.  
It focuses on backend development, database design, and RESTful API implementation.

## 🚀 Features
- User registration & authentication
- Pharmacy and product management
- Order placement and tracking
- Admin dashboard for system management
- Role-based access control
- CRUD operations for core entities

## 🛠️ Technologies Used
- C#
- ASP.NET Core
- Entity Framework Core
- SQL Server
- RESTful APIs
- Git & GitHub
